Connect the switch

Home Assistant — a switch Pixoo Screen (switch.pixoo_screen) appears automatically via MQTT discovery. Settings → Devices & Services → MQTT.
Apple Home — HA → enable HomeKit Bridge and include the switch; add it in the Apple Home app (or scan HA's HomeKit code there).
Alexa / Google — expose the switch via HA Cloud (Nabu Casa) or your existing Alexa/Google link, then say “turn Pixoo Screen off”.
